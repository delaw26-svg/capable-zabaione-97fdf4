Quick start

  1. Open Student Admission to register a learner.
  2. Keep the registration number displayed after submission.
  3. Administrators can add scores and publish results from Admin / Staff.
  4. Deploy the included folder to Netlify; follow README-SETUP.txt to enable shared online storage.

Student Records

Class Results — Enter Scores & Publish Together

Choose the school section, class, term and session. Enter CA and exam scores for every student and subject in the single score table below. Each score is entered once, saved together, and displayed in this same place for the admin to review. Totals, grades and remarks calculate automatically.

One-Place Class Score Entry & Record

Enter scores directly into this table. Existing saved scores appear here for editing. Use Save All Scores once after entering the class scores.

Publishing applies to students in the selected section and class for the chosen term/session, provided each student has at least one saved score.

Generate Result Access Codes

Generate as many codes as you need and hand one to each student when they need to check a result. Each code works only once: as soon as a student uses it, it is marked used and nobody else can use it. Leave "Any student" selected to create general codes, or pick a student to reserve codes for them only.
